# AI-BASED HIRING PREDICTION SYSTEM

## Complete Full-Stack Machine Learning Application

Build a complete, production-style **AI-Based Hiring Prediction System** that predicts whether a candidate is likely to be **Hired** or **Rejected** using resume and candidate information.

This is NOT just a machine-learning notebook.

Build a complete working application containing:

* Machine Learning pipeline
* Resume parsing
* AI hiring prediction
* Explainable AI
* FastAPI backend
* PostgreSQL database
* Complete React frontend
* Recruiter dashboard
* Candidate management
* Resume screening
* Prediction history
* Analytics dashboard
* Model performance dashboard
* Authentication
* Responsive UI
* API integration
* Docker
* Testing
* Documentation

The frontend must be a **fully implemented, polished web application**, not a simple form or basic Gradio interface.

---

# 1. PROJECT GOAL

Create an AI-powered recruitment platform where recruiters can:

1. Log in.
2. Upload a candidate's resume.
3. Automatically extract resume information.
4. Review and edit extracted information.
5. Run the machine-learning prediction.
6. See Hired/Rejected prediction.
7. See hiring probability.
8. Understand why the model made the prediction.
9. Save the candidate.
10. View candidate history.
11. Compare candidates.
12. View hiring analytics.
13. View model performance.
14. Manage candidates from a centralized dashboard.

The application should feel like a real **AI HR analytics SaaS product**.
