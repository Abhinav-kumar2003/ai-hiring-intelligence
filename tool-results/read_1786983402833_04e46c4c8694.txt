    12→    12→* Resume parsing

    15→    15→* FastAPI backend

    17→    17→* Complete React frontend
    18→    18→* Recruiter dashboard

    20→    20→* Resume screening
    21→    21→* Prediction history
    22→    22→* Analytics dashboard
    23→    23→* Model performance dashboard
    24→    24→* Authentication
    25→    25→* Responsive UI
    26→    26→* API integration
    27→    27→* Docker
    28→    28→* Testing

    35→    35→# 1. PROJECT GOAL
    36→    36→
    37→    37→Create an AI-powered recruitment platform where recruiters can:
    38→    38→
    39→    39→1. Log in.
    40→    40→2. Upload a candidate's resume.
    41→    41→3. Automatically extract resume information.
    42→    42→4. Review and edit extracted information.
    43→    43→5. Run the machine-learning prediction.
    44→    44→6. See Hired/Rejected prediction.
    45→    45→7. See hiring probability.
    46→    46→8. Understand why the model made the prediction.
    47→    47→9. Save the candidate.
    48→    48→10. View candidate history.
    49→    49→11. Compare candidates.
    50→    50→12. View hiring analytics.
    51→    51→13. View model performance.
    52→    52→14. Manage candidates from a centralized dashboard.
    53→    53→
    54→    54→The application should feel like a real **AI HR analytics SaaS product**.
